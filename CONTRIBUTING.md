# Contributing

Use Python 3.12 and the locked test environment. Add causal, seeded regression
tests for scientific changes, and distinguish synthetic checks from empirical
claims. Do not commit credentials, local datasets, fitted private parameters or
restricted third-party material. Sign contributions with the Developer Certificate
of Origin (`Signed-off-by`). AI assisted this release's packaging, documentation
and validation; original source authorship is retained in NOTICE and provenance.
